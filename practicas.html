Prácticas de Laboratorio

Catálogo oficial con las 12 prácticas formativas de cómputo y laboratorio establecidas en el plan de estudios institucional de TIC aplicadas al turismo. Desarrolla competencias en organizadores gráficos, ofimática avanzada, medios audiovisuales, desarrollo web, sistemas de distribución global (GDS) y modelado analítico en hojas de cálculo turísticas.

12 Prácticas Oficiales 30 Horas de Laboratorio Laboratorio de TIC Portafolio de Evidencias
Unidad I: Las TIC

Práctica 1: Organizadores gráficos digitales

Diseñar esquemas conceptuales y visuales que sinteticen los componentes fundamentales de las TIC, infraestructura de hardware/software y canales de comunicación en el sector turístico mediante herramientas colaborativas en la nube.

2 horas Canva Laboratorio de TIC
Unidad II: Digitalización de la información

Práctica 2: Procesador de textos

Aplicar herramientas avanzadas de formato editorial, estilos jerárquicos, tablas tarifarias, notas al pie, saltos de sección y referencias bibliográficas en formato APA para la elaboración formal de un Manual de Políticas y Servicios Turísticos.

2 horas Microsoft Word Laboratorio de TIC
Unidad II: Digitalización de la información

Práctica 3: Blog

Diseñar, estructurar y publicar una bitácora digital (blog) orientada a la difusión y marketing de contenidos turísticos, incorporando artículos de valor, galerías fotográficas, etiquetas temáticas y canales de interacción con el viajero.

3 horas Blogger Laboratorio de TIC
Unidad II: Digitalización de la información

Práctica 4: Página web

Construir una página web promocional para un destino o servicio turístico utilizando lenguaje de marcado semántico HTML5 y estilos CSS3 responsivos, garantizando accesibilidad, legibilidad y estándares de diseño digital.

3 horas Visual Studio Code Laboratorio de TIC
Unidad II: Digitalización de la información

Práctica 5: Presentaciones digitales con audio y video en medios de almacenamiento

Crear una presentación ejecutiva interactiva que articule diapositivas dinámicas, pistas de narración de audio calibradas y clips de video promocional optimizados, almacenándola y difundiéndola en medios locales y en la nube.

2 horas Microsoft PowerPoint Laboratorio de TIC
Unidad II: Digitalización de la información

Práctica 6: Sistemas de distribución global (GDS)

Simular las operaciones esenciales de un Sistema de Distribución Global (GDS): consulta de disponibilidades, cotización de tarifas aéreas y hoteleras, codificación/decodificación IATA y creación de un Registro de Nombre de Pasajero (PNR).

3 horas Simulador GDS (Amadeus / Sabre e-Learning / Portales B2B) Laboratorio de TIC
Unidad II / III: Hojas de cálculo

Práctica 7: Elementos de la hoja de cálculo

Dominar el entorno operativo de Microsoft Excel: barra de fórmulas, cinta de opciones, cuadros de nombres, formato numérico especializado (moneda, fecha, porcentaje) y validación de datos para la gestión hotelera.

2 horas Microsoft Excel o Google Sheets Laboratorio de TIC
Unidad III: Tratamiento de datos numéricos

Práctica 8: Operadores aritméticos y su orden de prioridad

Construir fórmulas matemáticas complejas aplicando operadores aritméticos (+, -, *, /, %, ^), de comparación y concatenación (&), respetando la jerarquía de operaciones y el uso estratégico de paréntesis para liquidación de servicios turísticos.

2 horas Microsoft Excel Laboratorio de TIC
Unidad III: Tratamiento de datos numéricos

Práctica 9: Funciones avanzadas y manejo de fórmulas

Aplicar funciones estadísticas (SUMA, PROMEDIO, CONTAR.SI, SUMAR.SI), lógicas condicionales (SI, Y, O) y financieras (PAGO) utilizando referencias relativas, absolutas ($) y mixtas para la gestión financiera de una agencia de viajes.

3 horas Microsoft Excel Laboratorio de TIC
Unidad III: Tratamiento de datos numéricos

Práctica 10: Elaboración de gráficos

Construir, formatear y personalizar gráficos estadísticos (columnas, líneas, circular y barras), incorporando elementos visuales complementarios (imágenes, figuras geométricas y cuadros de texto) para comunicar efectivamente la toma de decisiones turísticas.

2 horas Microsoft Excel Laboratorio de TIC
Unidad III: Tratamiento de datos numéricos

Práctica 11: Tablas dinámicas

Crear, configurar y manipular tablas dinámicas para resumir, cruzar y analizar grandes volúmenes de reservaciones turísticas, incorporando segmentación de datos interactiva (Slicers) y gráficos dinámicos sincronizados.

3 horas Microsoft Excel Laboratorio de TIC
Unidad III: Tratamiento de datos numéricos

Práctica 12: Impresión y exportación

Configurar de manera avanzada las propiedades de página, área de impresión, escala, márgenes, encabezados de fila repetidos y pie de página institucional para generar reportes impresos y archivos PDF con estándares profesionales de entrega directiva.

2 horas Microsoft Excel y visualizador PDF Laboratorio de TIC
